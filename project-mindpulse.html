🧠 AI & ML Project

Mind Pulse AI

An AI-powered mental health monitoring platform that provides early assessment, wellness insights, and personalized recommendations using NLP and machine learning.

AI & NLP Full Stack PostgreSQL Production Ready

📋 Project Overview

Mind Pulse AI is a comprehensive mental health monitoring platform designed to help individuals track, understand, and improve their mental wellbeing. By combining NLP-driven sentiment analysis, behavioral pattern recognition, and a conversational AI interface, the system offers clinically-inspired early assessment tools without replacing professional medical advice.

The platform provides daily mood tracking, cognitive behavioral therapy (CBT) inspired exercises, personalized wellness recommendations, and trend analytics — all through a premium, privacy-first interface.

❗ Problem Statement

Mental health issues affect over 1 billion people globally, yet access to professional support remains limited due to stigma, cost, and availability. Most mental health apps offer generic advice without personalization or early detection capabilities. There is a critical gap for an intelligent, accessible, and privacy-first mental health monitoring tool that leverages AI for meaningful early insights.

✅ Solution

Mind Pulse AI bridges this gap by:

  • Using NLP models to analyze user-written responses and detect emotional patterns (anxiety, depression indicators, stress levels)
  • Providing personalized wellness recommendations based on user history and detected patterns
  • Offering CBT-inspired exercises (breathing exercises, journaling prompts, mindfulness tasks)
  • Visualizing mood trends over time with interactive charts
  • Ensuring complete data privacy — all analysis done server-side with encrypted storage

⚡ Key Features

  • AI Mental Health Assessment — Multi-dimensional mood scoring using validated psychological scales (PHQ-9 inspired)
  • Sentiment Analysis Engine — Real-time NLP analysis of journal entries and responses
  • Personalized Wellness Plans — AI-generated daily wellness activities based on user profile
  • Mood Trend Dashboard — 7-day, 30-day, and 90-day mood visualization charts
  • CBT Exercise Library — Guided breathing, grounding techniques, and journaling prompts
  • Crisis Detection — Keyword-based alerts with professional resource referrals
  • Secure Authentication — bcrypt password hashing, session management
  • Email Notifications — Wellness reminders and weekly mood reports

🔄 API Flow

1

User submits daily mood check-in or journal entry via the frontend form

2

POST /api/assess — Express.js receives and validates the input, forwards to Python AI service

3

NLP Processing — Python engine tokenizes text, runs sentiment model, calculates PHQ-9 inspired score

4

Results stored in PostgreSQL with timestamp, user ID, scores, and detected emotions

5

GET /api/insights — Frontend fetches personalized recommendations and trend data for dashboard rendering

6

Email service sends weekly mood reports and reminders via Nodemailer/Resend

🗄️ Database Design

-- Users Table CREATE TABLE users ( id SERIAL PRIMARY KEY, name VARCHAR(255) NOT NULL, email VARCHAR(255) UNIQUE NOT NULL, password_hash VARCHAR(255) NOT NULL, created_at TIMESTAMP DEFAULT NOW() ); -- Mood Assessments CREATE TABLE mood_assessments ( id SERIAL PRIMARY KEY, user_id INT REFERENCES users(id), score DECIMAL(4,2) NOT NULL, -- 0.00 - 27.00 (PHQ-9 range) sentiment VARCHAR(50), -- positive/neutral/negative emotions JSONB, -- {anxiety:0.3, depression:0.1, ...} journal_text TEXT, recommendations JSONB, assessed_at TIMESTAMP DEFAULT NOW() ); -- Wellness Activities CREATE TABLE wellness_activities ( id SERIAL PRIMARY KEY, user_id INT REFERENCES users(id), activity_type VARCHAR(100), completed BOOLEAN DEFAULT false, completed_at TIMESTAMP );

🧗 Challenges Faced

  • NLP Model Accuracy — Mental health language is nuanced; trained on domain-specific datasets to improve sensitivity without causing false positives
  • Privacy-First Architecture — Designing a system that processes sensitive data while ensuring user privacy and regulatory compliance (GDPR considerations)
  • Crisis Detection Balance — Accurately detecting crisis indicators without over-triggering alerts required extensive threshold tuning
  • Real-time Performance — Optimizing the Python AI engine response time to under 2 seconds for seamless UX

🚀 Future Improvements

  • Integrate voice-based mood analysis using speech-to-text and audio sentiment models
  • Build a therapist dashboard for professionals to monitor consenting patients remotely
  • Add wearable device integration (heart rate, sleep data) for physiological mood correlation
  • Implement federated learning to improve models while preserving user privacy
  • Create a mobile app (React Native) for iOS and Android
  • Add multilingual support — Tamil, Hindi, and other Indian languages
